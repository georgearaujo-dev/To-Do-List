# 📝 To-Do List

Aplicação interativa de lista de tarefas desenvolvida para praticar os fundamentos do desenvolvimento web front-end.

> 🔗 **Deploy / Acesso online:** [Testar a aplicação]( https://georgearaujo-dev.github.io/To-Do-List/)

## Funcionalidades Atuais

- [x] Adicionar novas tarefas à lista
- [x] Marcar tarefas como concluídas
- [x] Excluir tarefas

## Próximas Implementações

- [ ] Persistência de dados com `LocalStorage` (salvar tarefas ao fechar/recarregar a página)
- [ ] Edição de tarefas existentes
- [ ] Responsividade e aprimoramento do design

## Tecnologias

- **HTML5:** Estrutura semântica
- **CSS3:** Estilização e layout
- **JavaScript:** Manipulação do DOM e lógica de eventos
